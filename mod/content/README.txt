Celeste Movement 0.2.10 / 蔚蓝运动候选版
Mod ID: Yinch.CelesteMovement
Requires DTMAPI Runtime 0.7.0.

能力映射读取当前存档实际解锁标记，不改写存档：未解锁为零次冲刺；
原版二段跳解锁一次蔚蓝冲刺，原版冲刺解锁两次蔚蓝冲刺（后者优先）。
已有存档自动对应，流程中获得能力后即时生效。没有空中二段跳。
普通冲刺和蹲姿冲刺共用次数，落地按蔚蓝恢复时序补满；第二次仍受原动作间隔限制。
未解锁或满次数时保持原发色；双冲剩一次为红发，次数耗尽为蓝发，恢复次数时短暂闪白。
抓墙、攀爬、蹬墙跳继续开局可用。原版剧情/教程文字尚未替换。

WASD / 方向键移动，沿用游戏跳跃和普通冲刺键。左 Ctrl 抓墙；C 蹲姿冲刺。
相反方向同时按下时采用后按方向。按下用于蹲伏/快落；单向平台上按下＋跳下穿。
实体地面上仍可蹲跳；冲刺中的下＋跳保留 hyper。下穿不会忽略邻近的下层平台。
角色运动固定使用蔚蓝逻辑，不再提供 F7 或配置菜单中的原生运动切换。
地面向下蹲伏；抓墙时上/下攀爬。键位可在 DTMAPI 配置菜单修改。
蹲伏改用独立 sit 屈腿帧与前倾网格调整，区别于此前的落地/空中轮廓；保留呼吸和滑行循环。
跳跃或其他动作可以立即打断过渡；身体和帽子同步，退出后恢复原生动画时钟。
仅在外观 Mod 缺少该原生动作时回退压低显示。墙跳上升使用原生 climb_jump。
攀爬采用运行时分层网格动画：脚部交替、手臂伸缩、身体起伏；节奏随垂直速度变化，
下降反向播放，停住后收回步行动作并保留轻微呼吸。使用当前角色/衣服/头发/帽子的
实际贴图和材质，不打包或替换原作美术。这是程序驱动动画，不是新增手绘逐帧图集。
网格沿用原贴图的排序轴心，避免蹲伏或攀爬变形导致前后遮挡跳变。
带 SpriteMask 的特殊图层保持原生显示，异形外观的骨骼位置仍需单独验证。
冲刺次数充满时保留当前换装的原生发色与材质；耗尽后渐变蓝色，恢复冲刺时闪白约 0.12 秒。
有效体力低于 20 时身体/帽子每 0.05 秒交替红闪；有效体力包含 wall boost 待返还部分。
头发提示使用原生分层与着色材质，保留部分贴图明暗。帽子遮发时不会强行显示头发。
整个人物贴图替换 Mod 没有可靠的头发分层，因此不对其单独染发；仍支持低体力提示。
配置菜单“播放动作预览”会在下一次进入/返回正常游戏时播放 14 秒动作和颜色展示，不移动角色。
配置菜单新增独立跳跃/普通冲刺：关闭“沿用游戏键位”后生效，默认 Space / 左 Shift。
八项键位均支持逐行恢复默认，修改后保存。冲突提示不保证覆盖全部原生交互/工具键。
独立键只影响蔚蓝运动接管；菜单、过场、骑乘等仍使用原生键位。
坐椅子/过场开始前先交还物理与动画；退出 Mod 时不会覆盖原生过场的无重力刚体状态。
空间比例默认 0.50，为 0.2.1 的一半；速度、跳高、冲刺距离和碰撞尺寸同步缩小，
动作时间与核心物理不变。配置菜单可调 0.25–1.00，保存后生效。
50% 是根据实际反馈选取的初始校准值，尚不能证明与原作视觉手感一致。

独立 60 Hz 逐像素运动核心：跑跳、离地宽限、输入缓冲、八方向冲刺、0.05 秒停顿、
抓墙体力、攀爬跳跃/体力返还、蹲姿碰撞箱、super/hyper/extended hyper/wavedash、
wallbounce、转角修正、单向平台、升降台速度继承。

候选版：与共享项目 Celeste 实现的 16 组固定场景、1920 帧对照通过，
覆盖跑跳、冲刺、hyper、攀爬和 wallbounce 等；不等于所有多洛可地形实机通过。
Unity 提供地形查询、触发器和游戏交互；外观仍使用多洛可动画。不添加蔚蓝专用机关。
移动物体挤压、复杂地形、暂停/切图/受伤/工具交接仍需回归验证。
先用复制存档。首次读档等待 DTMAPI WorldReady；同一存档后续切图若 LoadingWorld 滞留，确认原生正常控制、房间渲染及场景句柄连续稳定 0.25 秒后恢复接管。暂停、过场、骑乘和真实切图时继续让出控制；出生点小幅重叠会尝试修正或蹲姿接管。
运动尺寸按角色站立碰撞箱标定，不再随原游戏跑速/装备改变；模拟从帧更新驱动。
尚未证明原版手感一致。未知异常仍会记录错误并恢复原生物理以避免损坏游戏状态。
诊断日志包含动作名、像素速度、体力与充能。仅诊断开启时允许开发会话 jump/dash probe。
